# 多语言自动适配设计

## 目标

在现有 Vue i18n 基础上增加俄语，并统一浏览器语言、域名默认语言和手动选择的优先级。

## 语言优先级

```text
1. localStorage.locale：用户手动选择，最高优先级
2. navigator.languages / navigator.language：浏览器明确支持的语言
3. 当前域名默认值：cn 域名为 zh-CN，主域名为 en-US
4. 最终兜底：zh-CN
```

支持语言：`zh-CN`、`zh-TW`、`en-US`、`ru-RU`。

## 域名规则

域名只参与没有明确浏览器语言时的默认值，不覆盖俄语、繁体中文、英文等浏览器偏好。这样中国用户使用中文浏览器访问主域名仍显示中文，俄语浏览器访问任意域名显示俄语。

## 商品与站点字段

商品 SKU、站点配置、页脚链接等本地化字段使用统一回退：当前语言、英文、简体中文、繁体中文、对象中第一个非空值。旧数据没有 `ru-RU` 字段时仍可正常显示。

## 失败处理

俄文语言包懒加载失败时保持当前语言，不把界面切换成 key。未知或不支持的 locale 回落到域名默认语言。

## 验收

- 四种语言都能在语言菜单中选择。
- 浏览器 `ru`、`en`、`zh-CN`、`zh-TW` 能正确映射。
- `localStorage.locale` 覆盖浏览器和域名默认值。
- 未知浏览器语言在 `cn` 域名默认简中，在主域名默认英文。
- 商品和站点本地化数据兼容缺少俄文字段的旧数据。
- 前端测试和生产构建通过。
